F4 Milestone motion spec

Four moments animate in the app. Durations and curves follow the app_navix motion layer (rise · growY · pop, ease-out cubic-bezier(.16,1,.3,1)). Every animation plays once per change, never loops for more than 2 s, and is replaced by an instant state change when the phone has “Remove animations” on.

Flutter build notes

TweenAnimationBuilder / AnimatedContainer with Curves.easeOutCubic-equivalent Cubic(.16,1,.3,1). Respect MediaQuery.disableAnimations. HapticFeedback.lightImpact on step reached and level-up only. Golden tests capture frame 0 and the final frame of each animation, plus the reduced-motion version.

Triggers

All from server state (journey/status API or a push that refetches), never from a timer on the phone. If several steps were reached while the app was closed, only the latest plays.
